# Sunday Plan

Sunday Plan helps Washington State University students turn clubs, events and career opportunities into a short list of actions for the week. I started building it at WSU because opportunities were spread across too many places and I wanted a simpler way to decide what to do next.

[Try the public website](https://sunday-plan-wsu.zorenramirez.chatgpt.site) · [Read the project record](Sunday-Plan-Project-Record.md) · [Download the latest source](SundayPlan-98104e2.zip)

## November 24 website update

- The page heading shows today’s date. Your list shows the week it covers.
- Saving an opportunity takes one click. Scheduling is optional. Event dates and deadlines have explicit labels.
- Crimson and gray carry through the site. Each card expands independently, with secondary actions inside Details.

## Run the website

Download and extract the source ZIP. Open the included README for setup and run `npm test` in the extracted SundayPlan folder. The November 24 snapshot passed 70 Node tests and two Python tests.

The public tester saves in the current browser and may be an earlier release than the source snapshot. The project record covers design decisions, engineering checks and outstanding work.
